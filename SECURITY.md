# Security

If you find a security problem in Orbit, please **don't open a public issue**.

Report it privately instead:

- GitHub: [report a vulnerability privately](https://github.com/Avenger11764/Orbit/security/advisories/new), or
- the [support form](https://orbit-official-website.vercel.app/support) (choose "Something isn't working" and start the title with "Security").

Please include the Orbit version, your Windows version and the steps to reproduce. You'll get a reply as soon as possible, and the fix will be credited to you in the release notes if you'd like.

Orbit is supported in its latest version from the Microsoft Store.
